# 症例の追記方法

現在は、医師監修パンフレットから抽出した比較写真6組を `dist/assets/content.js` の `brochureGallery.records` で表示しています。ユーザーから写真使用の確認を受けて公開したものです。各組の `observations` に「術前・4か月後」と画像・寸法・代替テキスト、`sourcePosition` に原資料の位置を保存しています。写真の差し替えや追加時は、元の対応関係と原資料の表記を維持してください。

今後、新しく記録する症例は掲載同意と医師確認の後、同ファイルの `cases` に追加します。現在この配列は空ですが、パンフレット写真の表示とは独立しています。新規記録には以下のスキーマを使います。

経過写真のデータ形式は次のとおりです。これは構造の説明で、架空の症例や画像をサイトへ登録するものではありません。

```js
observations: [
  {
    label: '医師が確認した撮影時点・期間',
    image: 'assets/cases/承認済み画像の英数字ファイル名.webp',
    alt: '撮影方向と経過時点を説明する文'
  }
]
```

同じ症例の `observations` に、後日の記録を順番に追加します。`image` は `assets/cases/` 内の英数字のファイル名、拡張子はWebP・PNG・JPEGにしてください。治療内容・回数、費用総額、リスクも必須です。表示されるフラグを立てる前に、実際の承認記録と照合してください。

撮影期間は固定していません。撮影条件、撮影日、併用治療等の管理方法は担当医と確定してください。公開用画像に個人識別情報や位置情報を含めないでください。
