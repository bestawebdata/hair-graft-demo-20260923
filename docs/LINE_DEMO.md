# LINE画面の操作デモ

2026年9月24日。作成済みのLINEイメージ画像をもとに、ブラウザで操作できる画面を追加しました。

- 公開先：`https://bestawebdata.github.io/hair-graft-demo-20260923/line/`
- ローカル：`dist/line/index.html`
- 治療LPの希望登録欄とフッターからも移動できます。

## 体験できること

| 操作 | 表示・動作 |
| --- | --- |
| 治療について | 原資料に基づく概要、機器写真、施術の流れ |
| 医師紹介 | 上田医師の実写真、資料記載の経歴、担当体制の注記 |
| 症例を見る | 使用確認済みパンフレットの比較写真6組・12点 |
| 料金・リスク | 30万円（仮・検討中）、税込・税別等の確認中項目、リスクとダウンタイム |
| 希望地域 | 地域の選択、仮会場・開催日未定の案内、選択をフォームに引継ぎ |
| 希望登録 | 氏名、年代、居住地域、メールまたは電話、治療経験、希望地域、任意の質問 |
| デモ入力 | 架空の入力例を設定。選択済みの希望地域は維持 |
| 入力確認・修正 | 必須項目・連絡先形式を確認し、入力内容を表示。修正時は内容を保持 |
| 登録デモ完了 | 入力した氏名・連絡先などを消去。地域集約から日程案内への運用案を表示 |
| トークに戻る | 選択したメニューやデモ完了の案内をトークで確認。氏名・連絡先はトークに出さない |
| メニュー開閉・最初から試す | リッチメニューの開閉、入力・トーク履歴・完了表示のリセット |

PCではトークと案内画面を左右に並べ、700px以下では1画面ずつ切り替えます。戻るボタンとEscapeキーでトークへ戻れます。切替時には見出しや元のボタンへキーボードフォーカスを移します。

## 更新元

医療説明、医師、画像、料金、地域、会場は既存LPと共通の `dist/assets/content.js` を読み込みます。LINEデモ用に効能・医療条件・実施日を追加していません。入力例は `line-demo.js` のデモ入力処理で変更できます。

LINE風の画面は `dist/line/index.html`、見た目は `dist/assets/line-demo.css`、操作は `dist/assets/line-demo.js` です。画像は既存のWebPを使い、外部ライブラリ・外部フォント・外部スクリプトは読み込みません。

## 実際の接続・保存との違い

本デモはLINE SDK、LIFF、LINEログイン、Messaging APIには接続しません。実アカウントの作成・認証、友だち追加、メッセージ送信、受付・予約は行いません。

フォーム入力と操作履歴はページを開いている間のメモリ・DOM内だけで扱います。入力内容のネット送信、Cookie、ブラウザ保存領域、サーバーへの保存はありません。画像・HTML等の静的ファイルの読込みのみです。入力は完了時に消去し、選択した希望地域を完了案内とデモトークに残します。「最初から試す」か再読み込みで地域と操作履歴も消去されます。
