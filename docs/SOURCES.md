## 資料間の差と採用判断

- 事業計画中の「ダウンタイムなし」「特別なケア不要」は医師資料・同意書と相違するため採用しない。
- 医師資料の「安全性が高い」「アレルギーはほぼなし」は訴求文に使わず、同意書の「ゼロではない」を反映。
- 効果発現の期間、持続期間、他治療との比較、併用による効果向上は、原資料に記載があっても今回のLPでは訴求しない。
- 提携候補の具体的病院名、既存医院の住所・電話・QRコードは掲載しない。
- 将来の診察・予約案内の流れは今回の依頼に沿った運用案。現在の確定運用として扱わない。
- 初版では写真をすべて不使用。その後、医師紹介の実写真3点と機器・工程4点を反映。症例は当初ローカル確認版だけに仮配置したが、2026年9月23日のユーザー確認と保留指示の撤回を受け、パンフレットの比較写真6組を公開デモにも反映。
