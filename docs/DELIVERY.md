## ローカルで見る

`dist/index.html` をブラウザで直接開くか、Macでは `デモを開く.command` をダブルクリックしてください。ネット接続・ビルド・サーバーは不要です。別フォルダ `hair-graft-demo-local-review` も同じ最新版に同期しています。

GitHub Pagesは公開URLです。デモ表記と検索除外を設定しています。実際の受付・予約・送信はありません。
